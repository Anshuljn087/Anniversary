# Your music goes here

Drop an `.mp3` into this folder with the **exact filename** shown below, and
it replaces the synthesized fallback tune automatically the next time that
section plays — no code changes needed, just refresh (or redeploy if it's
already live).

| Filename needed | Plays during | Mood |
|---|---|---|
| `romantic.mp3` | Café Dates · Three Getaways | Acoustic / lo-fi |
| `drive.mp3` | Long Car Drives | Upbeat driving beats |
| `wedding.mp3` | The Sagai · The Shaadi · The Golden Night | Royal shehnai / wedding |
| `travel.mp3` | Thailand Honeymoon · The Travel Odyssey | Tropical / chill |
| `emotional.mp3` | Room Warmth · Special Memories · Grand Finale | Romantic piano climax |

If a file is missing, that zone just plays a synthesized version of the same
mood instead of silence — so the site always sounds complete, and you can
add real tracks gradually.

Keep each file reasonably small (under ~5MB, a couple of minutes long and
looped is plenty) since it's loaded in the browser — a full album-length
track isn't necessary.
